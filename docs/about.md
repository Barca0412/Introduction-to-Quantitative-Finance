**量化研究入门**是一个中文开源量化资源站，由湖南大学金融科技协会 Quant Group 维护。它包括量化研究教程、开源资源清单和研究方法笔记、研报与论文目录，以及每天更新的 FinPaperRadar（AI × 金融论文雷达）。

## 内容署名

不同内容的作者不同：有的出自个人，有的出自协会，有的来自课程团队。每一讲在开头注明署名；没有单独注明的页面由项目维护者整理。

## 如何引用

引用本项目：

```bibtex
@misc{introduction_to_quantitative_finance,
  title        = {量化研究入门 (Introduction to Quantitative Finance)},
  author       = {{湖南大学金融科技协会 Quant Group}},
  howpublished = {\url{https://github.com/Barca0412/Introduction-to-Quantitative-Finance}},
  note         = {GitHub repository}
}
```

引用 FinPaperRadar 数据集：

```bibtex
@misc{finpaperradar,
  title        = {FinPaperRadar: AI × Finance arXiv Paper Radar},
  author       = {{湖南大学金融科技协会 Quant Group}},
  howpublished = {\url{https://huggingface.co/datasets/Barca21412/FinPaperRadar}},
  note         = {Hugging Face dataset}
}
```

## 访问统计

为了了解哪些内容对读者有用，本站使用我们自己部署的开源统计工具 [Umami](https://umami.is/) 记录访问情况，比如页面浏览量、来源网站、停留时间，以及打开 PDF、点击代码链接这类操作。

- 不使用 cookie，也不跨站追踪；
- 不保存你的 IP 地址，也不收集姓名、邮箱等个人信息；
- 不记录你在论文雷达里搜索的内容，只记录"搜索过一次"；
- 数据保存在协会自己的服务器上，只用来改进内容，不提供给任何第三方。

首页显示的"此刻多少人在看、多少 agent 在读"和累计数，是服务器每分钟算一次的总数：

- 人数来自 Umami，"此刻"指最近 5 分钟内有活动的访客。已经识别出的 AI 爬虫（比如用真浏览器抓网页的 ExaSearchBot）不计入。
- agent 指 AI 爬虫和 AI 助手，数据来自网站服务器的访问日志，只统计在请求里自报身份的，比如 GPTBot、ClaudeBot、ChatGPT-User、PerplexityBot。伪装成普通浏览器的 agent 识别不出来，会被算成人。Google、Bing、百度这类普通搜索引擎不算 agent。
- 公开的只有这几个总数和"来过哪些 agent"，不公开任何访客的信息。

本项目用于教育与研究，不构成投资建议。
