# 关于

**量化研究入门**是一个中文开源量化知识库，由湖南大学金融科技协会 Quant Group 维护。它包括项目式教程、概念知识库、研报与论文目录，以及每天更新的 FinPaperRadar（AI × 金融论文雷达）。

## 内容署名

不同内容的作者不同：有的出自个人，有的出自协会，有的来自课程团队。每一讲在开头注明署名；没有单独注明的页面由项目维护者整理。

## 授权

- 仓库代码和整体项目：[MIT](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/blob/main/LICENSE)。
- 讲义：每一讲在开头注明授权方式。
- FinPaperRadar 数据集：我们生成的标签、中文摘要、评分和向量按 CC BY 4.0 授权；arXiv 元数据本身是 CC0。
- 研报和论文：版权归原作者和原机构所有，本项目只做学习研究用的索引。

## 如何引用

引用本项目：

```bibtex
@misc{introduction_to_quantitative_finance,
  title        = {量化研究入门 (Introduction to Quantitative Finance)},
  author       = {{湖南大学金融科技协会 Quant Group}},
  howpublished = {\url{https://github.com/Barca0412/Introduction-to-Quantitative-Finance}},
  note         = {GitHub repository}
}
```

引用 FinPaperRadar 数据集：

```bibtex
@misc{finpaperradar,
  title        = {FinPaperRadar: AI × Finance arXiv Paper Radar},
  author       = {{湖南大学金融科技协会 Quant Group}},
  howpublished = {\url{https://huggingface.co/datasets/Barca21412/FinPaperRadar}},
  note         = {Hugging Face dataset}
}
```
