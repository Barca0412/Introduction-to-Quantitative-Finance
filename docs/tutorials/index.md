# 教程

这里的每一讲都是一个完整的小项目：先说清要解决什么问题，再一步步写代码、跑结果、解读结果，最后指出容易踩的坑。代码用 AKShare、Tushare、yfinance 这类免费数据就能跑通。

## 怎么学

- **刚入门**：先读知识库里的[多因子投研框架](/wiki/framework)，知道一项量化研究由哪几步组成，再按顺序做讲义。
- **已经会写 Python**：直接挑感兴趣的一讲，打开"查看本讲代码"跟着跑。
- **想看前沿**：讲义末尾的"延伸阅读"会链接相关的研报、论文和[论文雷达](/arxiv/)。

每一讲都按同样的八节来写：要解决的问题、你会做出什么、数据与环境、分步实现、结果与解读、常见的坑、延伸阅读、练习。想投稿或改进讲义，请看仓库里的 [CONTRIBUTING.md](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/blob/main/CONTRIBUTING.md)。

本项目用于教育与研究，不构成投资建议。
