# 教程

本栏目的讲义来源于**湖南大学金融与统计学院唐国豪老师的《量化投资》课程**，整理后开源发布。欢迎大家跟着讲义一起学习这门课。

每一讲都是一个完整的小项目：先说清要解决什么问题，再一步步写代码、跑结果、解读结果，最后指出容易踩的坑。代码用 AKShare、Tushare、yfinance 这类免费数据就能跑通。

## 怎么学

- **刚入门**：先读知识库里的[多因子投研框架](/wiki/framework)，知道一项量化研究由哪几步组成，再按顺序做讲义。
- **已经会写 Python**：直接挑感兴趣的一讲，打开"查看本讲代码"跟着跑。
- **想看前沿**：讲义末尾的"延伸阅读"会链接相关的研报、论文和[论文雷达](/arxiv/)。

每一讲都按同样的八节来写：要解决的问题、你会做出什么、数据与环境、分步实现、结果与解读、常见的坑、延伸阅读、练习。

## 开放与合作

讲义和代码全部公开。你可以拿去自学，也可以用在课堂、读书会或社团活动里，授权方式见每一讲的开头。

我们也欢迎更多人一起把这套教程做好：

- **改进讲义**：发现错误、想补充例子或练习，直接提 issue 或 Pull Request，写法见 [CONTRIBUTING.md](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/blob/main/CONTRIBUTING.md)。
- **贡献新项目**：有好的量化研究小项目，欢迎按讲义模板整理后投稿。
- **课程与研究合作**：如果你在高校任教、带学生社团，或者在机构从事量化研究，想在课程、数据或研究上合作，欢迎通过[关于页](/about#合作与联系)的方式联系我们。

本项目用于教育与研究，不构成投资建议。
