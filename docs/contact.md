## 觉得有用

去 [GitHub 仓库](https://github.com/Barca0412/Introduction-to-Quantitative-Finance) 点一个 Star。Star 多了，能让更多做量化研究和 AI + 金融的同学找到这里。

## 发现错误，或者有问题想问

- 页面上的错字、错误的数据、失效的链接：在 GitHub [提一个 issue](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/issues/new/choose)，写清是哪一页、哪里不对。
- 想讨论一个想法，或者不确定算不算问题：去 [Discussions](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/discussions) 发帖。

维护者会在 7 天内首次回复每个 issue 和 PR。

## 推荐一个开源资源

- 用 issue 里的"推荐一个资源"模板填写，维护者整理后加入开源资源清单。
- 也可以直接提 PR：在 `data/registry/items/` 里加一条，写清它解决什么问题、适合谁、和清单里已有的同类项目有什么不同。
- 商业产品和自荐也可以，但请说明你和项目的关系，收费的标明价格。

## 改讲义，或者投一讲新教程

- 小的修正可以直接提 [Pull Request](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/pulls)。
- 想写一讲新教程：先在 [Discussions](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/discussions) 说一下想法，再按仓库 `templates/tutorial/` 的模板写。一讲是一项完整的小研究，代码要能从头跑通。
- 投稿规则见仓库的 [CONTRIBUTING.md](https://github.com/Barca0412/Introduction-to-Quantitative-Finance/blob/main/CONTRIBUTING.md)。

## 给论文雷达提建议

- 有该收录却没收录的论文、分错类的论文：提一个 issue，附上论文链接。
- 想到新的分类维度，或者新的趋势和洞察的展示方式：也欢迎提 issue，我们一起把雷达做得更好。
